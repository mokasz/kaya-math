# Kaya's Math Studio (洗足学園 空間図形 3D解説)

洗足学園の数学（空間図形など）の理解を深めるための、Three.js を用いたインタラクティブ 3D 解説アニメーション集です。

🌐 **公開URL**: [https://mokasz.github.io/kaya-math/](https://mokasz.github.io/kaya-math/)

---

## 📚 収録コンテンツ

| No | タイトル | 主な機能・特徴 | リンク |
|:---|:---|:---|:---|
| **夏明け12** | 三角柱の切断と立体の体積 | 立体切断ステップ解説、3D回転・ズーム、等積変形 | [開く](natsuake12.html) |
| **夏明け17** | 空間内を動く球の通過領域（軌跡） | リアルタイム軌跡アニメーション、XYZ軸スライダー操作、MathJax数式 | [開く](natsuake17.html) |

---
